## 6. 提交选项 —— 认证备注（Notes for certification）

> 这是**审核团队唯一能看到的说明**，强烈建议填写（中英文均可）：

```
1. runFullTrust: This is an Electron desktop app packaged with electron-builder;
   the runFullTrust restricted capability is added automatically by the packaging
   toolchain and is required for the app to function.

2. First-run behavior: On first launch, the app extracts a bundled runtime
   archive (dsh.zip, part of the app package, NOT downloaded from the internet)
   into the user's %APPDATA% folder. This may take 1-3 minutes; a splash screen
   shows progress. No additional software is downloaded or installed.

3. Testing: The app requires a DeepSeek API key to use AI features.
   A test API key for review: <在这里填入一个专用的测试 Key>
   After launching, enter the key in the web UI settings page.

4. Network: The app only connects to api.deepseek.com when the user initiates
   AI tasks. No telemetry or third-party data sharing.
```

**注意：** 如果不提供可用的测试 API Key，审核员无法测试核心功能，
这是最常见的被拒原因（"无法访问/测试应用功能"）。建议在 DeepSeek 控制台
创建一个低额度的专用 Key 填入，审核通过后可随时吊销。

## 7. 提交流程速查

1. 打 tag 触发 CI：`git tag v0.1.3 && git push origin v0.1.3`
2. 约 5~10 分钟后在 Actions 产物下载 `DeepSeek Harness-0.1.3.msixupload`
3. 合作伙伴中心 → 你的应用 → 开始提交 → 按上面第 1~5 节填写
4. 「程序包」环节上传 `.msixupload` 文件
5. 「提交选项」粘贴第 6 节认证备注
6. 提交认证，通常 1~3 个工作日出结果
