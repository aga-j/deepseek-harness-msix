# 隐私政策 / Privacy Policy

生效日期：2026-08-20

## 中文

DeepSeek Harness 桌面客户端（以下简称"本应用"）是一个本地运行的桌面外壳程序，用于在你的电脑上启动并显示 DeepSeek Harness 的 Web 界面。

### 我们收集什么

本应用**不收集、不上传、不分析**任何用户数据。应用本体不包含任何遥测、统计或崩溃上报功能。

### 数据存储在哪里

应用运行时产生的数据（会话记录、日志、工作区文件）全部保存在你自己的电脑上：

- `%APPDATA%\DeepSeekHarness`：运行时组件、会话与日志
- `C:\Users\<用户名>\DeepSeekHarness`：Agent 的工作区目录

卸载应用不会自动删除上述用户数据，你可以随时手动删除。

### 网络通信

- 本应用仅在你主动使用时，通过 DeepSeek Harness 本体与你配置的 **DeepSeek API（api.deepseek.com）** 通信，用于完成你发起的 AI 对话与 Agent 任务。发送内容即你输入的指令及相关上下文，其处理受 [DeepSeek 隐私政策](https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html) 约束。
- 应用不会将你的数据发送给任何其他第三方。
- 应用不会将数据用于广告或用户画像。

### 联系我们

如有隐私相关问题，请通过 GitHub 仓库提 Issue：
https://github.com/aga-j/deepseek-harness-msix/issues

## English

DeepSeek Harness Desktop ("the App") is a locally-run desktop shell that launches and displays the DeepSeek Harness web UI on your machine.

### What we collect

The App **does not collect, upload, or analyze** any user data. It contains no telemetry, analytics, or crash reporting.

### Where your data lives

All runtime data (sessions, logs, workspace files) is stored locally on your computer:

- `%APPDATA%\DeepSeekHarness`: runtime components, sessions, and logs
- `C:\Users\<you>\DeepSeekHarness`: the Agent workspace

Uninstalling the App does not remove this data; you may delete it manually at any time.

### Network communication

- The App communicates only with the **DeepSeek API (api.deepseek.com)** that you configure, solely to fulfill the AI conversations and agent tasks you initiate. Such processing is governed by the [DeepSeek Privacy Policy](https://cdn.deepseek.com/policies/en-US/deepseek-privacy-policy.html).
- The App does not send your data to any other third party, and does not use it for advertising or profiling.
